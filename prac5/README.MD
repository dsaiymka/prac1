# Practice 5: Python Regular Expressions (RegEx)

## 1. Цель
Практика посвящена изучению регулярных выражений в Python с помощью модуля `re`.  
В рамках задания изучены методы поиска, совпадений, разбиения и замены текста с использованием шаблонов RegEx.  

## 2. Содержание

### 2.1 Изучение RegEx
- Основы регулярных выражений
- Метасимволы: `. * + ? ^ $ [] | () \`
- Специальные последовательности: `\d`, `\w`, `\s`, `\D`, `\W`, `\S`, `\A`, `\Z`
- Квантификаторы: `{n}`, `{n,}`, `{n,m}`
- Функции: `re.search()`, `re.findall()`, `re.split()`, `re.sub()`, `re.match()`
- Флаги: `re.IGNORECASE`, `re.MULTILINE`

### 2.2 Практическое задание: Парсер чеков
Файл `receipt_parser.py` выполняет парсинг чека из `raw.txt`.  
Извлекается:
- Названия товаров
- Цены
- Общая сумма
- Дата и время
- Способ оплаты  

Результат выводится в **JSON формате**.
